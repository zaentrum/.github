Report a security hole in private: use “Report a vulnerability” on this repository's Security tab. Don't open a public issue.

You get an answer within 7 days.

## What happens to a report

Only the maintainers see a report until a fix is out. The answer says whether
the report is taken as a security hole. The fix goes out in a release, and the
release's notes name it and thank whoever reported it, unless they ask not to
be named.

## What a report can be about

The platform's code, its images and its documentation: everything the
repositories of the zaentrum organisation hold, and every image and file they
publish.

An installation somebody runs is theirs. A report about one goes to whoever
runs it.
