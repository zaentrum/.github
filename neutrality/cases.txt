# The neutrality check's own test cases. check.sh runs them before every scan,
# and alone with --self-test; a case gone wrong stops the check with exit 2.
# Like rules.txt, this file names what the rules ban, so the check leaves its
# directory out of the scan.
#
# One case per line:
#
#   <kind> <rule> <text>
#
#   kind  hit         the rule must flag the text, read as code;
#         miss        the rule must let it pass, read as code;
#         prose-hit   the rule must flag the text, read as prose;
#         prose-miss  the rule must let it pass, read as prose;
#   rule  a rule's name from rules.txt, or * with miss and prose-miss: no
#         rule may flag it;
#   text  the rest of the line, without its leading and trailing blanks.
#
# Blank lines and lines that start with # are ignored. The self-test fails
# unless every rule has a hit case and a miss case; every word of a rule has
# a hit case that the word alone flags; a rule of scope all has a prose-hit
# case, and a rule of scope code a prose-miss case that it flags as code; and
# every pass in rules.txt has a miss case that only the pass lets pass.
